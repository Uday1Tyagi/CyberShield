# ⚙️ CyberShield Backend

This backend handles all cybersecurity modules and APIs.

## 📦 Modules

* Malware Detection
* Email Phishing Detection
* URL Scanner
* USB Protection

## 🚀 Setup

```bash
pip install -r requirements.txt
python app.py
```

## 🔗 API Usage

* `/malware` → Scan files
* `/email` → Detect phishing
* `/url` → Check website safety
* `/usb` → Monitor USB devices
